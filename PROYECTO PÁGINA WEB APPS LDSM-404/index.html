01. Manifiesto & Visión

Propósito del Sitio

Este espacio digital es un híbrido entre un semiportafolio mis visiones y un moodboard creativo. Su objetivo es documentar mi evolución en el desarrollo de software, exhibir la lógica detrás de mi código y plasmar mis intereses estéticos, sirviendo como una carta de presentación interactiva.

Público Objetivo

Diseñado para reclutadores del sector tecnológico y mentes creativas. Está pensado para quienes buscan inspiración en la intersección entre la ingeniería estructurada y la cultura alternativa, demostrando que el código limpio también tiene un alto impacto visual. Solo quiero retratar mi visión y pasión a través de este espacio digital.

03. Esenciales

Herramientas, hardware y equipamiento táctico que conforman mi ecosistema de desarrollo y rutina diaria.

Techwear & Transporte

Organización utilitaria. Una backpack de diseño táctico (estilo Oakley) que soporta el desgaste del día a día. Estructura modular indispensable para transportar todo el hardware, cables y periféricos de forma segura.

Servidor In-House

Nodo de operaciones central. Una Mini PC configurada como servidor local con conexión remota (SSH). El entorno perfecto para alojar bases de datos MySQL, virtualizar sistemas Linux y mantener proyectos corriendo 24/7 sin depender de la nube.

Estación de Desarrollo

El núcleo de compilación. Ya sea la versatilidad de una laptop o la fuerza bruta de una PC de escritorio con gráficos dedicados. Potencia pura requerida para levantar entornos pesados como Android Studio o Docker sin comprometer el rendimiento.

Terminal Móvil

El entorno de pruebas en la palma de la mano. Un smartphone Android con interfaz limpia (como la experiencia pura de un Pixel con graphene). Fundamental para testear aplicaciones nativas, probar la responsividad de los sitios web y tener acceso constante al servidor local.

04. El Archivo

TandeoLeón & Interfaces UI

Desarrollo de soluciones tangibles. Desde el diseño de interfaces y wireframes para plataformas de adopción de mascotas (React/Tailwind), hasta la arquitectura de TandeoLeón, una app en Android para monitorear cortes de agua usando Kotlin, Java y Firebase.
